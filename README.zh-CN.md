## ✨ 核心特色

### 🖥️ 高分辨率显示完美支持
这是本 Fork 版本最重要的特色功能：

- **Windows 高 DPI 缩放适配** - 完美支持 Windows 系统下的高分辨率缩放设置，告别模糊界面
- **macOS HiDPI 原生支持** - 在 macOS Retina 显示屏上呈现清晰锐利的游戏画面
- **丝滑视觉体验** - 界面文字和图形边缘清晰，如同原生 Retina 应用般流畅

无论你使用 2K、4K 显示器，还是 MacBook 的 Retina 屏幕，都能获得最佳的视觉体验。

## 🚀 快速开始

### 推荐方式：使用启动器

配合 [Another OpenUO Launcher](https://github.com/openuo-online/Another-OpenUO-Launcher) 启动器使用，体验更加顺滑：

- 自动管理客户端版本更新
- 便捷的多账号配置
- 一键启动游戏
- 更流畅的使用体验

### 手动安装

1. 前往 [Releases](../../releases/latest) 页面下载最新版本
2. 解压到任意目录
3. 运行客户端，享受高清游戏体验

### 系统要求

- **Windows**: Windows 10/11（推荐开启高 DPI 缩放）
- **macOS**: macOS 10.15 或更高版本（完美支持 Retina 显示）
- **.NET**: .NET 8.0 或更高版本

## 📖 功能说明

### 高 DPI 设置建议

**Windows 用户：**
- 系统设置中可以设置任意缩放比例（125%、150%、200% 等）
- 客户端会自动适配，保持界面清晰锐利
- 无需额外配置，开箱即用

**macOS 用户：**
- 在 Retina 显示器上自动启用 HiDPI 渲染
- 文字和图形都以 2x 或更高分辨率渲染
- 获得原生应用级别的显示质量

### 脚本功能

- 支持录制游戏操作为脚本
- 可设置循环次数或无限循环
- 通过 UI 界面轻松管理脚本参数

## 🔧 编译说明

### 前置要求
- .NET 8.0 SDK
- Git

### 编译步骤

**Windows:**
```bash
git clone --recursive https://github.com/[your-repo]/ClassicUO.git
cd ClassicUO
build.bat
```

**macOS/Linux:**
```bash
git clone --recursive https://github.com/[your-repo]/ClassicUO.git
cd ClassicUO
chmod +x build.sh
./build.sh
```
